# 予約なし版（HPだけ）／ simple

WEB予約システムを使わない、**ホームページだけ**のバージョンです。
本番サイトとは別物として並んでいるので、見比べたり、そのまま切り替えたりできます。

- 公開URL： https://em2026music.github.io/yatsumori-rental/simple/
- 本番（予約あり）： https://em2026music.github.io/yatsumori-rental/

## 何が違うか

| | 本番（親フォルダ） | この予約なし版（simple/） |
|---|---|---|
| WEB予約フォーム | あり | **なし**（すべて電話ボタンに置換） |
| 予約の確認・変更 | あり | なし |
| Supabase（DB・ログイン） | 使う | **一切使わない**（完全に静的HTML） |
| ページ編集エディタ | 使える | 使えない（HTMLを直接編集） |
| 画像 | 一部はSupabaseストレージ | すべてリポジトリ内（`assets/img/home/`） |
| 3言語（日/英/繁） | トップ・料金・アクセス・予約 | トップ・料金・アクセス |

予約導線はすべて **電話 070-2472-3633**（`tel:` リンク＝スマホならタップで発信）に置き換えてあります。

## 中身

```
simple/
├ index.html      PCトップ（1536px固定・いまの公開トップと同じ見た目）
├ mobile.html     スマホトップ（390px固定）※スマホは自動でこちらへ
└ pages/          案内ページ12枚（料金・ギャラリー・初心者ガイド・アクセス 他）
```

画像・CSS・JSは複製せず、親フォルダの `../assets/` を共有しています（リポジトリを重くしないため）。
そのため **このフォルダだけ切り離して使うことはできません**。単独で使いたい場合は `assets/` も一緒にコピーしてください。

## 作り直し方（元サイトを更新したあと）

`simple/` は**自動生成**です。手で直すこともできますが、元サイトを大きく変えたときは作り直すのが早いです。
生成スクリプトは会話用の作業フォルダにある `build_simple.py`（PCトップは Supabase の公開データ `site_pages(home)` を取ってきて静的化しています）。

手で直す場合の注意：

- `simple/` の中に `reserve.html` へのリンクを増やさないこと（予約なし版の意味がなくなる）
- Supabase の `<script>`（supabase-js / supabaseClient.js / pageRenderer.js）は入れないこと
- 3言語の文言は `../assets/js/i18n.js` の辞書に足す
